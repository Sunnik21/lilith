# Charts and dashboards (U12 to U16)

Load when the scanner lists a chart library or the screen has charts. Same rule of the cut: same chart type, same data, same series colors.

- **U12.** Title names the chart type ("Bar chart of revenue") → "Monthly revenue".
- **U13.** "Hover for details", "Each bar is a month" → delete.
- **U14.** The same value said 3 times (bar + label + gridline + sentence) → keep one. KPI: number, one direction cue, period ("▲ 12% vs last month").
- **U15.** Boxes, heavy gridlines, 3D, shadows and glows on chart marks → delete or make hairline gray.
- **U16.** Legend for 1 to 4 series → label lines directly.
