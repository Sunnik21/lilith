# Fix S8: no limits

Require login for AI endpoints, add a per-user limit, and set a monthly spending cap in the AI provider's dashboard.
```ts
import { Ratelimit } from "@upstash/ratelimit";
import { Redis } from "@upstash/redis";
const ratelimit = new Ratelimit({ redis: Redis.fromEnv(), limiter: Ratelimit.slidingWindow(20, "1 h") });
const { success } = await ratelimit.limit(user.id);
if (!success) return new Response("Too many requests", { status: 429 });
```
Express: `express-rate-limit` on login/signup routes. Supabase Edge Functions: a per-user usage table checked before the call.
