# Fix S6: trusting what the browser says

- Look prices up on the server (Stripe Price IDs or your database); the browser sends only a plan name, checked against an allowlist.
- Take `userId` from the session, never the body.
- Write only named fields: `data: { name }`, never `data: req.body`.
- Check admin rights on the server for every admin endpoint, from your database, not from the request.
- Block users from updating their own `role`/`plan` column (see fixes/S3.md).
