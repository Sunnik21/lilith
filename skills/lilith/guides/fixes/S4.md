# Fix S4: API routes with no login check

```ts
export async function POST(req: Request) {
  const supabase = await createClient();            // server client with the user's cookies
  const { data: { user } } = await supabase.auth.getUser();
  if (!user) return new Response("Unauthorized", { status: 401 });
  // ...work only with data that belongs to user.id
}
```
JWT: `jwt.verify(token, secret, { algorithms: ["HS256"] })`, never `jwt.decode` for auth. Server actions need the same check at the top.
