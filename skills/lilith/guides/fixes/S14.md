# Fix S14: headers, CORS and HTTPS

Allow only your own domains when credentials are on (an allowlist checked before reflecting the origin). Add basic headers (Next.js `headers()` in `next.config`, or the host's config):
```
Strict-Transport-Security: max-age=63072000; includeSubDomains
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
```
