# Fix S2: secret keys sent to the browser

Move the call to the server: a Next.js route handler or server action, a Supabase Edge Function, a Netlify/Vercel function. The browser calls your endpoint; only the server holds the key. Then rotate the key (S1).

```ts
// app/api/chat/route.ts  (server only)
import OpenAI from "openai";
const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY }); // no NEXT_PUBLIC_
export async function POST(req: Request) {
  // check the user is logged in first (S4) and limit usage (S8)
  const { message } = await req.json();
  const r = await openai.chat.completions.create({ model: "gpt-4o-mini", messages: [{ role: "user", content: message }] });
  return Response.json({ reply: r.choices[0].message.content });
}
```
