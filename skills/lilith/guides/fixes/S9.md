# Fix S9: unsafe HTML and code execution

Render as text (React does this by default). If HTML is needed, sanitize it: `DOMPurify.sanitize(html)`, or a Markdown renderer without raw HTML (`react-markdown`). Use parameterized queries (Prisma `findMany`, tagged `$queryRaw`), never `$queryRawUnsafe` with input. Never pass user input to `exec`.
